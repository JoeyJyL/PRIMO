## Sets and Indices

- $\mathcal{V} = \{v_1, v_2, v_3, v_4\}$: original vertiport nodes
- $\mathcal{E} = \{e_1, e_2, e_3, e_4\}$: original flight corridor links
- $\mathcal{V}^b = \{v_5\}$: candidate backup nodes
- $S = \{s_1, s_2, s_3\}$: O-D demand pairs
- $\Omega$: set of all disruption scenarios $(ev, k)$
- $\mathcal{M} = \{0, 1, 2\}$: capacity levels for each backup node

## Parameters

- $\bar{c}_{v_i}$: undisturbed node capacity
- $\bar{c}_{e_j}$: undisturbed link capacity
- $c_{ev,k}$: disturbed capacity under scenario $(ev,k)$
- $p_{ev,k}$: probability of scenario $(ev,k)$
- $p_{\text{dis}} = 0.8$: total disruption probability
- $C^{b}_{im}$: capacity of backup node $i$ at level $m$ ($C^b = [0, 1, 2]$)
- $F_{im}$: cost of building backup node $i$ at level $m$ ($F = [0, 4, 6]$)
- $\Delta^{\text{adj}}_{vi}$: 1 if backup node $i$ is adjacent to original node $v$
- $f = 6$: budget, $w = 0.1$: cost-benefit factor
- $E$: incidence matrix, $E_+$: element-wise absolute value

## Decision Variables

- $Z_{im} \in \{0,1\}$: 1 if backup node $i$ is assigned capacity level $m$
- $X'_{es}(ev,k) \geq 0$: flow on link $e$ for demand $s$ under scenario $(ev,k)$
- $D'_{1,vs}(ev,k) \geq 0$: fulfilled demand at destination $v$ for demand $s$
- $D'_{2,vs}(ev,k) \geq 0$: generated demand at origin $v$ for demand $s$

## Objective

$$\max \;\; (1 - p_{\text{dis}}) \cdot S^*(\mathcal{N}(0,0)) + \sum_{(ev,k) \in \Omega} p_{ev,k} \sum_{v,s} D'_{1,vs}(ev,k) - w \sum_{i,m} F_{im} Z_{im}$$

## Constraints

### (C1) Flow Conservation (per scenario)

$$\sum_e E_{ve} \cdot X'_{es}(ev,k) = D'_{1,vs}(ev,k) - D'_{2,vs}(ev,k), \quad \forall v, s, (ev,k)$$

### (C2) Link Capacity (per scenario)

$$\sum_s X'_{es}(ev,k) \leq c^{\mathcal{E}}_e(ev,k), \quad \forall e, (ev,k)$$

### (C3) Node Capacity with Backup — Indicator Constraint Formulation

The original formulation uses an auxiliary continuous variable $\hat{c}_b = \sum_m C^b_{bm} Z_{bm}$ for backup capacity, then adds $\Delta^{\text{adj}}_{vb} \cdot \hat{c}_b$ to the disrupted node's capacity in a single linear constraint.

This is replaced by **indicator constraints indexed by capacity level**: for each disrupted node $v$ adjacent to backup node $b$, instead of one linear constraint with the auxiliary variable, we have one indicator constraint per capacity level $m$:

**Non-disrupted nodes (no backup):**
$$\sum_{e,s} E^+_{ve} X'_{es}(ev,k) \leq \bar{c}_v, \quad \forall v \text{ not disrupted}$$

**Disrupted node $v$ adjacent to backup $b$ — Indicator formulation:**
$$Z_{bm} = 1 \;\Rightarrow\; \sum_{e,s} E^+_{ve} X'_{es}(ev,k) \leq c_{v,k} + \Delta^{\text{adj}}_{vb} \cdot C^b_{bm}, \quad \forall m \in \mathcal{M}$$

This eliminates the auxiliary continuous variable $\hat{c}_b$ entirely.

**Disrupted node not adjacent to any backup:**
$$\sum_{e,s} E^+_{ve} X'_{es}(ev,k) \leq c_{v,k}$$

### (C4) Flow Balance

$$\sum_v D'_{1,vs}(ev,k) = \sum_v D'_{2,vs}(ev,k), \quad \forall s, (ev,k)$$

### (C5) Demand Constraints

$$D'_{1,vs} \leq \Delta^1_{vs} \cdot M, \quad D'_{2,vs} \leq -\Delta^2_{vs} \cdot M$$

### (C6) Capacity Selection

$$\sum_{m \in \mathcal{M}} Z_{im} = 1, \quad \forall i \in \mathcal{V}^b$$

### (C7) Budget Constraint

$$\sum_{i,m} F_{im} Z_{im} \leq f$$

## Key Modeling Difference

The original formulation introduces an **auxiliary continuous variable** $\hat{c}_b$ to represent the selected backup capacity via $\hat{c}_b = \sum_m C^b_{bm} Z_{bm}$, then uses this variable linearly in node capacity constraints. This reformulation **eliminates the auxiliary variable** and directly uses **indicator constraints** $Z_{bm} = 1 \Rightarrow \text{capacity limit} = c_{v,k} + C^b_{bm}$ for each capacity level $m$. Since exactly one $Z_{bm} = 1$ (by C6), exactly one indicator constraint is active per scenario, enforcing the correct capacity limit without the continuous relaxation of $\hat{c}_b$.
